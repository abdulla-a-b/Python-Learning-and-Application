§ One

Two Kinds of Knowledge দুই ধরনের জ্ঞান

Programming is not about telling the computer the answer. It is about telling the computer how to find the answer.

Declarative knowledge is a statement of fact — "The square root of 16 is 4." You're told the answer.

Imperative knowledge is a recipe, a how-to — "To find a square root, start with a guess, refine it by averaging, repeat until close enough." You're told the procedure.

Programming is the craft of writing imperative recipes that generate declarative facts. When you write a program, you are not handing the computer the answer — you are handing it instructions for finding the answer.

বাংলায়

জ্ঞান দুই রকমের: ঘোষণামূলক জ্ঞান হলো সরাসরি ফ্যাক্ট ("১৬-এর বর্গমূল ৪"), আর নির্দেশমূলক জ্ঞান হলো কাজের পদ্ধতি বা রেসিপি ("বর্গমূল বের করতে একটা আনুমানিক মান নাও, গড় বের করে কাছাকাছি যাও")।

প্রোগ্রামিং মানে রেসিপি লেখা — যাতে কম্পিউটার সেই রেসিপি চালিয়ে নিজে থেকে উত্তর বের করতে পারে। আমরা উত্তর দিই না, উত্তর বের করার পথ দিই।

§ Two

The Square Root Example বর্গমূল বের করার উদাহরণ

Let's find √16 using only basic arithmetic — no calculator. We'll discover an algorithm by following our nose.

Start with any guess g. Then iterate:

  1. If g × g is close enough to x, stop — g is the answer.
  2. Otherwise, improve the guess: new_g = (g + x/g) / 2
  3. Repeat.

Watch how fast it converges:

gg × gx / g(g + x/g) / 2
395.3334.17
4.1717.363.8374.0035
4.003516.02773.9974.000002

This is Newton's method — the same algorithm running inside the calculator app on your phone right now.

বাংলায়

ক্যালকুলেটর ছাড়া, শুধু যোগ-গুণ-ভাগ দিয়ে ১৬-এর বর্গমূল বের করতে চাই। একটা আনুমানিক মান g নাও (যেমন ৩), তারপর — যদি g × g মোটামুটি ১৬-এর কাছাকাছি হয়, কাজ শেষ। না হলে, নতুন g হবে পুরোনো g আর ১৬/g এর গড়। মাত্র তিন বার চক্র চালালেই উত্তর ৪.০০০০০২ — প্রায় নিখুঁত। এটাই নিউটনের পদ্ধতি, যা আপনার ফোনের ক্যালকুলেটরও ভেতরে ভেতরে ব্যবহার করে।

§ Three

What Is an Algorithm? অ্যালগরিদম কী?

From the square root example, we can extract the definition. An algorithm has three essential parts:

  1. A sequence of simple steps — each step on its own is easy to do.
  2. A flow of control — rules saying when each step runs (sometimes you repeat, sometimes you skip).
  3. A stopping condition — a way to know when you're done.

Algorithms are recipes. Recipes are algorithms.

অ্যালগরিদম মানেই রেসিপি। রেসিপি মানেই অ্যালগরিদম।

Baking a cake from a box has all three parts:

  1. Mix dry ingredients (step)
  2. Add eggs and milk (step)
  3. Pour mixture in a pan (step)
  4. Bake at 350°F for 5 minutes (step)
  5. Stick a toothpick in the cake (step)
  6. If toothpick is not clean, repeat steps 4–5 (flow of control)
  7. If toothpick is clean, take pan out (stopping condition)
  8. Eat 🍰
বাংলায়

অ্যালগরিদমের তিনটি অংশ আবশ্যিক: (১) সরল ধাপগুলোর ক্রম — প্রতিটা ধাপ একা একা সহজ; (২) নিয়ন্ত্রণ প্রবাহ — কখন কোন ধাপ চলবে, কখন পুনরাবৃত্তি হবে; (৩) থামার শর্ত — কখন বুঝবে কাজ শেষ। কেক বানানোর রেসিপিও এই তিনটাই অনুসরণ করে — মেশানো, বেক করা, কাঠি দিয়ে পরীক্ষা, ঠিকঠাক হলে বের করা, না হলে আরও বেক করা।

§ Four

Computers Execute Algorithms কম্পিউটার অ্যালগরিদম চালায়

A computer does only two things:

  • Performs simple operations — billions per second.
  • Remembers results — gigabytes of storage.

The operations are either built-in (like +) or defined by you, the programmer.

A computer will only do exactly what you tell it to do — nothing more, nothing less.

কম্পিউটার শুধু সেটাই করবে যা আপনি বলেছেন — বেশিও না, কমও না।

A bit of history

Fixed-program computers (pre-1940s): hard-wired for one algorithm. Like a desk calculator — useful, but locked.

Stored-program computers (1940s onward): the machine stores instructions in memory alongside data. Programs are no different from other kinds of data. This Von Neumann insight is what made modern computing possible — and what made viruses, compilers, and operating systems even conceivable.

বাংলায়

কম্পিউটার মাত্র দুইটা কাজ করে: সহজ অপারেশন চালায় (সেকেন্ডে শত শত কোটি বার) আর ফলাফল মনে রাখে (গিগাবাইট পরিমাণ)। পুরোনো কম্পিউটার একটাই অ্যালগরিদম চালাতে পারত। ১৯৪০-এর দশকে ভন নিউম্যান বললেন: প্রোগ্রাম আর ডেটা একই জিনিস — দুটোই বিট, দুটোই মেমোরিতে রাখা যায়। এই অন্তর্দৃষ্টিই আধুনিক কম্পিউটিং সম্ভব করেছে।

কম্পিউটারের চার অংশ: মেমোরি (ডেটা ও নির্দেশনা রাখে), কন্ট্রোল ইউনিট (পরের নির্দেশনা ঠিক করে), এএলইউ (হিসাব করে), আর ইনপুট/আউটপুট (তথ্যের আসা-যাওয়া)।

§ Five

Turing's Universality টিউরিং-এর সর্বজনীনতা

Alan Turing proved something astonishing: any computation can be done with just six primitive operations on a tape — left, right, print, scan, erase, no-op. Six. That's it.

Real programming languages give you hundreds of conveniences on top of this minimal core, but the foundation needs only six.

Anything computable in one programming language is computable in any other. Python is not magic — it is comfortable notation.

যা পাইথনে লেখা যায়, তা অন্য যেকোনো ভাষাতেও লেখা যায়। পাইথন বিশেষ কিছু নয় — শুধু আরামদায়ক একটা লেখার রীতি।

বাংলায়

অ্যালান টিউরিং প্রমাণ করেছেন: মাত্র ছয়টা মৌলিক অপারেশন দিয়ে দুনিয়ার যেকোনো হিসাব করা যায় — বাম, ডান, প্রিন্ট, স্ক্যান, মুছে ফেলা, কিছু না করা। মাত্র ছয়টা! এই তথ্য থেকে বোঝা যায় — পাইথন, জাভা, সি, রাস্ট — যেকোনো ভাষাতেই একই হিসাব করা যায়। ভাষা বদলায়, কিন্তু কী হিসাব করা যাবে সেটা বদলায় না।

প্রোগ্রামের সবসময় একটাই নির্দিষ্ট মানে থাকে — কিন্তু সেটা আপনি যা চেয়েছিলেন তা নাও হতে পারে। আপনার সমস্ত বাগ এই ফাঁকটার মধ্যেই বাস করে।

§ Seven

Where Things Go Wrong ভুল কোথায় হয়

Three categories of errors, ordered from easiest to most dangerous:

  1. Syntax errors — the interpreter complains immediately. Easy to fix.
  2. Static semantic errors — caught at runtime in Python. Annoying but usually clear.
  3. Different meaning than intended — the worst category. Three flavors:
    • Program crashes mid-run
    • Program runs forever (infinite loop)
    • Program produces an answer — but the wrong one (most dangerous: it looks like it works)

§ Eight

Objects & Types অবজেক্ট এবং টাইপ

Everything in Python is an object, and every object has a type. The type defines what operations are legal.

  • 30 is a number — you can add, subtract, multiply, divide it.
  • 'Ana' is a string — you can slice it, concatenate it, but you cannot divide it by a number.

Objects come in two flavors: scalar (cannot be subdivided) and non-scalar (have internal structure — lists, dictionaries, strings).

The four scalar types you need first:

TypeMeansExamples
intintegers5, -100, 0, 1234
floatreal numbers3.27, 2.0, -1.5
booltruth valuesTrue, False
NoneType"nothing"None (only one value)

Use type(x) to ask Python what type a value has. This is one of the most important debugging habits you can build.

§ Nine

Type Conversion (Casting) টাইপ পরিবর্তন

You can convert between types explicitly:

  • float(3) → 3.0 (int becomes float)
  • int(3.9) → 3 (truncation, not rounding — important!)
  • int(3.1) → 3 (also truncates)

But round() does proper rounding:

  • round(3.9) → 4
  • round(3.4) → 3
Common pitfall: Students confuse int() with round(). int(7.9) is 7, not 8. Always test in the console.

§ Ten

Expressions & Operators এক্সপ্রেশন ও অপারেটর

An expression combines objects with operators and evaluates to a single value with a type.

OpMeaningExampleResult
+sum3 + 25
-difference5 - 32
*product4 * 28
/division (always float)6 / 32.0
//floor division7 // 23
%remainder7 % 21
**power2 ** 38

Type rules

  • If both operands are int (except /), result is int.
  • If either is float, result is float.
  • / always returns float in Python 3.

Operator precedence (highest to lowest)

  1. **
  2. * / % // — left to right
  3. + - — left to right

Parentheses override everything — just like math.

Replace complex expressions with one value. Work systematically — inside-out, left-to-right.

§ Eleven

Variables & Binding ভেরিয়েবল ও বাঁধাই

Math variables and CS variables look the same but behave differently. This trips up almost every beginner.

MathComputer Science
x is abstract — represents all possible values x is bound to one specific value at a given time
x * x = y means "for all x, y is x squared" x = 5 means "store 5 in the box named x"
= is equality = is assignment, not equality

The assignment pi = 355/113 does two things, in order:

  1. Evaluate the right-hand side → gets 3.1415929...
  2. Bind that value to the name on the left → pi now refers to that value

From then on, typing pi retrieves the stored value.

What's NOT allowed

  • 6 = x ✗ — the left side must be a name, not a value
  • x*y = 3+4 ✗ — same reason; left must be a single name

বাংলায়

গণিতের x আর কম্পিউটার সায়েন্সের x এক জিনিস নয়। গণিতে x বিমূর্ত, যেকোনো মান হতে পারে; কম্পিউটারে x একটা নির্দিষ্ট সময়ে একটামাত্র মান ধারণ করে। = মানে অ্যাসাইনমেন্ট, সমতা নয়।

pi = 355/113 লিখলে দুইটা কাজ হয়: (১) ডান পাশের হিসাব করো → পাও 3.1415929; (২) বাম পাশের নামে বাঁধো → এখন pi মানে সেই মান। বাম পাশে সবসময় একটামাত্র নাম থাকতে হবে — ভ্যালু বা এক্সপ্রেশন নয়।

§ Twelve

The Re-Binding Gotcha সূক্ষ্ম ফাঁদ: পুনঃবাঁধাই

This is the single concept that confuses beginners most. If you understand only one thing from this lecture, make it this.

Look carefully:

pi = 3.14
radius = 2.2
area = pi * (radius ** 2)   # area is computed NOW → 15.1976
radius = radius + 1           # radius becomes 3.2
# area is STILL 15.1976 — it does NOT update!

Python stores the computed value, not the formula. Lines run in order. Nothing recomputes automatically.

পাইথন ভ্যালু রাখে, ফর্মুলা নয়। লাইনগুলো ক্রমানুসারে চলে। কোনো স্বয়ংক্রিয় পুনঃহিসাব নেই।

This is the opposite of a spreadsheet, where changing a cell triggers downstream updates. In Python, you must re-execute the formula if you want the new answer.

বাংলায়

এই একটা ধারণা নতুনদের সবচেয়ে বেশি ধাঁধায় ফেলে। area = pi * radius ** 2 লিখলে area তখনই হিসাব হয়ে যায়। পরে radius বদলালেও area নিজে থেকে পরিবর্তন হবে না — এটা এক্সেলের উল্টো। নতুন মান পেতে হলে আবার লাইনটা চালাতে হবে।

সোয়াপ ধাঁধা: y = x লিখলে y-এর পুরোনো মান হারিয়ে যায়। তাই temp দিয়ে পুরোনো মান সংরক্ষণ করতে হয় — temp = x; x = y; y = temp।

§ Thirteen

Code Style — Names Are Documentation কোড স্টাইল

The same code, three styles. Read all three and feel the difference.

Meh — terse, no context

# do calculations
a = 355/113 * (2.2**2)
c = 355/113 * (2.2*2)

Okay — single-letter names, comments compensating

p = 355/113
r = 2.2
# multiply p with r squared
a = p * (r**2)
# multiply p with r times 2
c = p * (r*2)

Best — descriptive names, comments explain intent

# calculate area and circumference of a circle
# using an approximation for pi
pi = 355/113
radius = 2.2
area = pi * (radius ** 2)
circumference = pi * (radius * 2)

Code is read far more often than it is written. Good names mean less commenting and fewer bugs.

কোড লেখার চেয়ে পড়া হয় অনেক বেশি। ভালো নাম দিলে কম কমেন্ট লাগে, কম বাগ হয়।

বাংলায়

একই কোড তিন রকম স্টাইলে লিখলে পার্থক্য বোঝা যায়। মাঝারি: এক অক্ষরের নাম, প্রসঙ্গ নেই। ঠিক আছে: ছোট নাম, কিন্তু কমেন্ট দিয়ে পুষিয়ে দেওয়া। সবচেয়ে ভালো: pi, radius, area — নাম দেখলেই উদ্দেশ্য বোঝা যায়। কোড পড়া হয় অনেক বেশি — ছয় মাস পরে নিজেই পড়বেন, সহকর্মীরা পড়বেন। ভালো নাম দেওয়া হলো ভবিষ্যৎ নিজের প্রতি দয়া।

§ Summary

Seven Big Ideas সাতটি বড় ভাবনা

If you remember nothing else from this lecture, remember these seven sentences.

1

Programming = writing recipes to generate facts.

প্রোগ্রামিং মানে রেসিপি লেখা, ফ্যাক্ট নয়।

2

An algorithm = steps + flow of control + stopping condition.

অ্যালগরিদম = ধাপ + নিয়ন্ত্রণ + থামার শর্ত।

3

A computer does only exactly what you tell it to do.

কম্পিউটার শুধু আপনার নির্দেশই পালন করে।

4

A program has exactly one meaning — but it may not be what you intended.

প্রোগ্রামের একটাই মানে — কিন্তু সেটা আপনার ইচ্ছার সাথে নাও মিলতে পারে।

5

Every object has a type. Types decide what operations are valid.

প্রতিটি অবজেক্টের টাইপ আছে। টাইপ ঠিক করে কোন অপারেশন বৈধ।

6

= is assignment, not equality. It binds a value to a name.

= মানে অ্যাসাইনমেন্ট, সমতা নয়। এটা নামের সাথে ভ্যালু বাঁধে।

7

Lines run in order. Values don't recompute automatically.

লাইনগুলো ক্রমানুসারে চলে। ভ্যালু নিজে থেকে আবার হিসাব হয় না।
